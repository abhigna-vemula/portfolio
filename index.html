01
Computer Vision · Image Forensics

Edge-Enabled Deepfake & Image Forgery Detection

A real-time forensics pipeline that flags deepfake, forged, and AI-generated images for surveillance systems — built to run on constrained edge hardware, with no cloud dependency.

Problem

Surveillance and content-verification pipelines need to catch manipulated footage quickly, without shipping raw frames to the cloud for every check.

Approach

Combined noise-residual analysis and edge-artifact detection with a lightweight EfficientNet-B0 classifier in a multi-stage pipeline — pre-filter, forensic feature extraction, then CNN classification — engineered for edge deployment under strict compute constraints.

Challenges

  • Keeping inference light enough for edge hardware without losing sensitivity to subtle forgery artifacts
  • Balancing false positives against real-time throughput requirements

Key features

  • Multi-stage detection pipeline (noise + edge artifacts + CNN)
  • No cloud dependency — fully on-device
  • Built for real-time surveillance use cases

Stack

Python OpenCV EfficientNet-B0 CNN Computer Vision

Lessons learned

Model-size-vs-forensic-sensitivity trade-offs are the whole game on constrained hardware — a heavier cloud model catches artifacts this one has to work harder for.

02
NLP · Machine Learning

AI Resume Screening & Candidate Ranking System

An NLP system that screens and ranks resumes against a job description automatically — turning a manual, inconsistent process into a repeatable one.

Problem

Manually screening large resume pools against a job description is slow and inconsistent between reviewers.

Approach

Text preprocessing and TF-IDF vectorization to represent resumes and job descriptions, Logistic Regression to predict candidate suitability, and cosine similarity scoring to rank candidates — all served through a Flask web interface.

Challenges

  • Making similarity scoring resistant to keyword-stuffed resumes
  • Keeping the ranking explainable, not a black box

Key features

  • TF-IDF vectorization + cosine similarity ranking
  • Logistic Regression suitability scoring
  • End-to-end Flask web interface

Stack

Python NLP Machine Learning Flask

Lessons learned

Classical NLP — TF-IDF plus a linear model — gets you surprisingly far before you need to reach for a transformer.

03
Robotics · Computer Vision · Geospatial

SandSight — Smart India Hackathon Finalist

An autonomous rover that maps beach sand grain-size in the field, in real time — replacing slow lab sieving with a camera, controlled lighting, and a CV pipeline.

National Finalist, Hardware Edition — Smart India Hackathon 2025, team TEDH

Problem

Grain-size analysis (D10 / D50 / D90) traditionally needs lab sieving — slow, and impractical across large stretches of coastline.

Approach

Built a three-wheeled autonomous rover with a camera-based imaging rig and controlled lighting, paired with CV/ML pipelines that estimate D10, D50, and D90 grain-size metrics directly from images — then shipped a geospatial platform with backend inference APIs and a real-time dashboard.

Challenges

  • Getting consistent grain-size estimates under variable field lighting and terrain
  • Syncing hardware, inference, and dashboard under hackathon time pressure

Key features

  • Autonomous rover with controlled-lighting imaging rig
  • D10 / D50 / D90 grain-size estimation via CV/ML
  • Live geospatial dashboard with backend inference APIs
  • Firebase authentication, cloud storage & sync

Stack

Computer Vision Machine Learning Firebase REST APIs

Lessons learned

What it takes to ship hardware, ML inference, and a frontend dashboard together, as a team, against a national-finals deadline.

04
NLP · Regression

Movie Script Rating Prediction

Predicts a movie's rating directly from its raw screenplay text — before a single frame is shot.

Problem

Understanding whether a script is on track quality-wise usually waits until post-production or release — far too late to act on.

Approach

TF-IDF vectorization of raw screenplay text feeding a Linear SVR model, framed as regression to predict a continuous rating score rather than a category.

Challenges

  • Screenplays are long and structurally noisy — formatting and stage directions can drown out real signal

Key features

  • Raw-text ingestion straight from screenplay files
  • TF-IDF feature extraction
  • Linear SVR-based rating prediction

Stack

Python NLP Machine Learning

Lessons learned

Regression framing versus classification matters when the thing you're predicting — subjective creative quality — is genuinely continuous.

How I Work

01

02
